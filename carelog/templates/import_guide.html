How imports work

Reference information for teams that want to review file handling, validation, and evidence treatment.

Import files

Simple by default

Upload, check, review

01Upload

Choose the facility and add the original exports.

02Automatic checks

CareMin identifies records, validates fields, and withholds anything ambiguous.

03Review

You receive a clear receipt with included records, warnings, and next actions.

Files you can use

Export directly from your existing system. Do not reshape the file to fit a CareMin template.

Supported formats

CSV, TSV, text, Excel, JSON, SQL, SQLite, and ZIP.

Each upload request is currently limited to 4.5 MB by the platform edge.

Common records

Worked staffing, planned rosters, residents, occupied bed days, staff credentials, and optional delivered-care records.

Evidence treatment

CareMin keeps evidence streams separate so a plausible-looking number cannot hide a source problem.

Source evidenceTreatment
Approved timesheets, payroll, or clocking recordsMay be classified as actual worked.
Planned schedules and rostersRemain rostered and do not become actual results.
Ambiguous source or staff classificationWithheld as unverified until reviewed.
Original filesRetained with the import receipt as audit evidence.
