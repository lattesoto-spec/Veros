Demo environment

A demo organisation is a normal tenant with generated sample data, created from the command line so it can be rebuilt at any time: 

flask --app app seed-demo --password 'a-long-demo-password'

It is deliberately a separate organisation — demo data must never sit beside a real client's records. Delete it by removing the organisation's data from inside it, the same as any other tenant.
